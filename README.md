# 🏏 IPL Team Performance Dashboard

Welcome to the **IPL Team Performance Dashboard** project! This repository contains a comprehensive Excel-based data analysis tool designed to track, visualize, and summarize key performance metrics of teams in the Indian Premier League (IPL).

---

## 📋 Project Overview

This dashboard provides an in-depth summary of IPL match data, offering quick insights into team standings, runs scored, wickets taken, and venue statistics. It leverages Microsoft Excel using pivot tables and data aggregation techniques to turn raw match data into actionable insights for cricket enthusiasts and analysts.

## ✨ Key Features

*   **Overall Team Summaries:** Displays total matches played, total wins, total runs scored, and total wickets taken for each major franchise.
*   **Run Aggregation:** Analyzes the total runs accumulated by each team across the tracked matches.
*   **Win Type Breakdown:** Compares match outcomes based on the margin of victory, categorizing aggregated statistics by **Win by Runs** (defending) vs. **Win by Wickets** (chasing).
*   **Venue Statistics:** Tracks match volume and data across major iconic stadiums.
*   **Backend Aggregation:** The provided data acts as the calculation engine (via Pivot Tables) to feed dynamic visual dashboard elements.

## 🚀 How to Use

1.  **Download the File:** Clone or download this repository to access the core Excel workbook (`Project1.xlsx`).
2.  **Open in Excel:** Launch the file using Microsoft Excel (2016 or newer is recommended for optimal Pivot Table and Dashboard support).
3.  **Navigate the Sheets:**
    *   **Raw Data / Source:** The foundational data for all calculations.
    *   **Team Summary:** Contains the aggregated tables (found in the CSV) tracking runs, wickets, wins, and venues.
    *   **Dashboard:** The visual representation (charts/graphs) of the summary data.
4.  **Interact:** If configured, use the Excel slicers to filter the dashboard by specific teams, venues, or win types to see the metrics update dynamically.
